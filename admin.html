1. Доступ до керування

Увійдіть за допомогою особистого GitHub-токена з дозволом Contents: Read and write для цього репозиторію.

Токен не зберігається в браузері та не надсилається на сторонні сервери. Він використовується лише для запитів до GitHub. Нікому не пересилайте свій токен.

2. Нова демоверсія

Один MP3 до 20 МБ. Існуючі файли та пісні не замінюються.

Натискаючи «Додати пісню», ви публікуєте її для всіх відвідувачів сайту. Перевірте назву й авторів.

Як отримати доступ

Кожен автор використовує власний обліковий запис GitHub. Власник репозиторію надає Світлані право запису через Settings → Collaborators → Add people. Після прийняття запрошення вона створює власний fine-grained token для цього репозиторію з дозволом Contents: Read and write.

Сайт статичний, тому права визначає GitHub. Не вводьте тут пароль GitHub — лише окремий токен.
